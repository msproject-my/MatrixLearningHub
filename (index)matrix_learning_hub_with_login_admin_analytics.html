User Manual & Method Overview

3x3 Matrix Linear Equation Solver Guide

1. Gaussian Elimination Method

Converts the augmented coefficient matrix [A | B] into Upper Triangular Matrix form via Elementary Row Operations (ERO), then applies Back Substitution to solve for variables x, y, z.

2. Doolittle LU Decomposition Method

Decomposes matrix A = L · U where lower matrix L has unit diagonal elements (Lii = 1). Solves L · y = B (forward substitution) and subsequently U · x = y (back substitution).

3. Crout LU Decomposition Method

Decomposes matrix A = L · U where upper matrix U has unit diagonal elements (Uii = 1). Solves L · y = B and subsequently U · x = y.
