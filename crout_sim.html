Crout Method User Manual

Crout Method (LU Decomposition):

The system AX = B is solved by decomposing coefficient matrix A into two triangular matrices L and U (A = L · U).

L = [[a, 0, 0], [b, c, 0], [d, e, f]]
U = [[1, g, h], [0, 1, i], [0, 0, 1]]

Solution Steps:

  1. L & U Decomposition: Find values a, b, c, d, e, f (for L) and g, h, i (for U).
  2. Forward Substitution (LY = B): Solve for values y1, y2, y3.
  3. Back Substitution (UX = Y): Solve for values z, y, x.
