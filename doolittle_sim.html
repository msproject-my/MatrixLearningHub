Doolittle LU Decomposition Method

What is Doolittle LU Decomposition?

The Doolittle Method factors a square matrix A into the product of a lower triangular matrix L and an upper triangular matrix U:

In Doolittle's variation, matrix L has diagonal elements equal to 1:

Solving Steps:
  1. Step 1: Formulate the linear system into matrix form AX = B.
  2. Step 2 (Decomposition): Equate LU = A to solve for variables d, e, f, a, g, h, b, c, i.
  3. Step 3 (Forward Substitution): Solve LY = B for intermediate vector Y = (y₁, y₂, y₃)ᵀ.
  4. Step 4 (Back Substitution): Solve UX = Y for solution vector X = (x, y, z)ᵀ.
