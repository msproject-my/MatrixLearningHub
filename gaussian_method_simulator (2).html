User Manual - Gaussian Elimination Method

Simulation Overview

This simulator solves a 3-variable linear system ($x, y, z$) using the **Gaussian Elimination Method** with row cross-multiplication to convert the matrix into an upper triangular form for back substitution.

Step-by-Step Guide:

  1. Step 1 (Matrix Form): Convert linear equations into matrix notation $[A][X] = [B]$.
  2. Step 2 (Augmented Matrix): Combine the coefficient matrix and constant vector into $[A|B]$.
  3. Step 3 (Eliminate $a_{21}$ and $a_{31}$): Apply row cross-multiplication $R_{2(new)} = a_{11}R_2 - a_{21}R_1$ and $R_{3(new)} = a_{11}R_3 - a_{31}R_1$ to zero out row 2 and row 3 in column 1.
  4. Step 4 (Eliminate $a_{32}$): Apply $R_{3(new)} = R_{2,col2}R_3 - R_{3,col2}R_2$ to complete the Upper Triangular Matrix.
  5. Step 5 (Back Substitution): Calculate $z$, substitute to find $y$, and lastly solve for $x$.
